How It Works
Caesar: Each letter shifts by a fixed amount.
A→D, B→E, C→F with shift=3.

Vigenère: Uses a keyword — each letter shifts by the keyword's letter position, cycling through.

Frequency attack: In English, 'E' appears ~12.7%, 'T' ~9.1%. Map the most-frequent cipher letter back to 'E' to guess the key.

Encryption Modes — ECB vs CBC vs CTR
Cryptography · Lab
Tool 05
Message Input
Message is split into 4-char blocks. Watch how each mode treats identical blocks.
ECB — Electronic Codebook
Each block encrypted independently. Identical blocks → identical ciphertext.
Patterns leak! Never use ECB.
CBC — Cipher Block Chaining
Each block XOR'd with previous ciphertext before encrypting. Uses an IV.
Good confidentiality. Vulnerable to padding oracle.
CTR — Counter Mode
Encrypts a counter value, XORs result with plaintext. Turns block cipher into stream cipher.
Parallelisable, no padding. Recommended.
